## [sSI_and_sTraceMIN](https://github.com/JingyuLiuMath/sSI_and_sTraceMIN)

MATLAB research code for the sketched subspace iteration (sSI) and sketched TraceMIN (sTraceMIN). This is a joint work with Dr. [Yuqi Liu](https://izayoiyuuki.github.io/).

## [FIO](https://github.com/JingyuLiuMath/FIO/)

MATLAB research code for the fast direct inversion of Fourier integral operators (FIOs). This is a joint work with Prof. [Yingzhou Li](https://yingzhouli.com/).

## [funm_quad_sketch_and_restart](https://github.com/JingyuLiuMath/funm_quad_sketch_and_restart)

A sketch-and-restart framework for computing the action of a matrix function on a vector, $f(A)b$, where $A$ is large, sparse, and non-Hermitian. This is a joint work with Prof. [Stefan Güttel](https://guettel.com/) and Dr. [Lauri Nyman](https://sites.google.com/view/laurinyman/home).

## [NUFFT2D](https://github.com/JingyuLiuMath/NUFFT2D)

MATLAB research code for the fast direct inversion of 2D nonuniform discrete Fourier transforms (NUDFTs). This is a joint work with Prof. [Yingzhou Li](https://yingzhouli.com/).
